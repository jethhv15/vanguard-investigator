# Vanguard Investigator

Android Performance Investigation Framework.

## Vision

Vanguard Investigator is an Android Performance Investigation Framework.

Its mission is to inspect Android performance scientifically by collecting evidence, validating subsystem relationships, identifying anomalies, bottlenecks, imbalances, and broken execution flows.

Vanguard Investigator never optimizes the system.

It only investigates.
