# Report Model

Version: 1.0 (Frozen)

---

# Purpose

The Report Model defines the standard investigation output.

Reports communicate investigation results in a structured and explainable format.

---

# Report Structure

Investigation Summary

↓

Observed Problem

↓

Evidence

↓

Validation

↓

Correlation

↓

Diagnosis

↓

Root Cause

↓

Impact

↓

Confidence

↓

Recommendations (Optional)

---

# Report Rules

Every report must:

- Reference evidence
- Explain conclusions
- State confidence
- Remain reproducible

---

# Confidence Levels

- Low
- Medium
- High
- Verified

---

# Recommendations

Recommendations are optional.

Reports never modify Android.

---

# Final Statement

Reports explain Android behavior.

Reports never change Android behavior.
