# Constitution

Version: 1.0 (Frozen)

---

# Purpose

The Constitution defines immutable engineering rules.

Unlike principles,

these rules are mandatory.

Violation of these rules requires architectural justification.

---

# Rule 1

Evidence First

No conclusion may exist without evidence.

---

# Rule 2

Never Guess

Unknown is always better than a false conclusion.

---

# Rule 3

One Responsibility

Every component has exactly one responsibility.

---

# Rule 4

Inspect Before Diagnose

Diagnosis without inspection is prohibited.

---

# Rule 5

Validate Before Report

Every diagnosis must be validated before entering the report.

---

# Rule 6

Every Metric Needs Context

Metrics without context are meaningless.

---

# Rule 7

Every Problem Must Have Evidence

Problems are never reported without supporting evidence.

---

# Rule 8

Every Evidence Must Be Traceable

Every evidence must identify:

- Source
- Timestamp
- Collector
- Collection Method

---

# Rule 9

Correlation Before Root Cause

Root cause analysis requires subsystem correlation.

Isolated metrics are insufficient.

---

# Rule 10

Never Modify Android

Vanguard Investigator never changes:

- Android configuration
- Kernel configuration
- CPU governor
- Scheduler
- Thermal configuration
- Memory configuration

Investigator observes only.

---

# Rule 11

Everything Is Explainable

Every output must be understandable.

Black-box conclusions are prohibited.

---

# Rule 12

Truth Above Expectations

The investigation follows evidence,

not user expectations.

---

# Final Statement

When evidence and assumptions disagree,

evidence wins.
